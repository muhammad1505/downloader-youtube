## Cakupan dan hasil

Permintaan pengelola: pertahankan perubahan lokal UI player, selaraskan seluruh menu, periksa pesan file hilang saat membuka video, dan telusuri galat LRCLIB dari riwayat HP. Acuan tambahan: [pemetaan delapan skill](../.agents/skills/tubeflow-dev/references/supporting-skills.md).

Checkpoint ini memperbaiki bug fungsional pada working tree 1.1.17/code31. Perubahan pengguna dipertahankan; tidak ada migrasi atau dependensi baru pada tahap ini.

| Temuan | Akar dan solusi | Bukti |
|---|---|---|
| BUG-060: pesan file hilang setelah video terbuka | `launchFile` menyamakan hasil sukses `null` dengan URI kosong. Pemeriksaan URI dipisah dari hasil launcher. | Tiga tes mencakup buka/bagikan audio/video, URI kosong, dan kegagalan launcher. |
| BUG-061: JSON galat LRCLIB menjadi cache positif | Cache menerima objek JSON apa pun selama 24 jam. Kontrak per endpoint kini diperiksa sebelum penyimpanan dan saat membaca cache lama. | Fixture respons salah skema, retry pulih, dan cache lama lulus. Belum terbukti sebagai penyebab galat riwayat pengguna. |
| BUG-062: judul bernomor cocok dengan lagu berbeda | Skor substring meloloskan Satru/Satru 2 jika artis dan durasi dekat. Angka judul inti kini harus sama. | Tes Satru/Satru 2/Satru 3 serta label kualitas 4K lulus. |
| Hasil manual tanpa timestamp menutupi hasil bertimestamp dengan ID sama | `putIfAbsent` mempertahankan hasil pertama. Varian berikut kini dapat melengkapi liriknya. | Fixture pencarian multi-varian lulus. |

Cooldown 429, Retry-After, cache lagu lain, gerbang versi/artis/durasi ±2 detik, dan jurnal publikasi LRC tetap dipertahankan. Tidak ada penggeseran waktu global atau penerimaan otomatis versi studio untuk rekaman live.

## Hasil final 1.1.18/code32

### Implementasi dan akar tambahan

- **BUG-064:** hasil inspeksi lama dapat meninggalkan galat setelah link dihapus.
  `InspectionState` mengikat metadata, playlist, busy, error dan detail ke token
  pemilik. Clear membatalkan token sebelum engine/coroutine; callback lama tidak
  boleh mengubah sesi baru. Cache metadata selesai tetap diperiksa URL-nya saat enqueue.

  navigasi menggunakan ikon dengan nama aksesibilitas lengkap; label normal tetap ada.

### Batas dan pekerjaan berikutnya

- Lirik yang ada pada pencarian manual belum tentu cocok otomatis. Audio SATRU
  pengguna berdurasi 332,352 detik; 20 hasil probe tidak memiliki kandidat dalam
  selisih 3 detik. Gerbang otomatis tetap ±2 detik, identitas dan versi. Tidak
  melonggarkan pencocokan, mengarang timestamp, atau menerapkan offset global.
- Perbaikan cache/skema dan HTTP diuji fixture. Tidak terbukti seluruh galat lama
  berasal dari cache invalid, dan tidak sengaja memicu 429 nyata. Gangguan provider
  masih mungkin terjadi; kode HTTP baru membantu diagnosis kejadian berikutnya.
- Gaya/komponen yang disentuh telah dipoles dan diperiksa. TalkBack/switch access menyeluruh,
  font 2× (UI ColorOS hanya sampai 1,6×), tablet/foldable, Android 12+ dynamic color,
  semua dialog destruktif dan seluruh kombinasi error belum diuji.
- Pengujian A/B alignment akhir, karaoke lagu penuh, pemulihan di tengah mati
  proses, storage penuh/grant dicabut, benchmark 3.000 media dan runtime 16KB
  tetap mengikuti backlog. Tes yang belum dijalankan tidak dinyatakan lulus.
- Tidak menerbitkan ke toko atau membuat server karaoke. Ini hasil perbaikan
  terverifikasi sesuai cakupan, bukan klaim seluruh gerbang produksi telah terpenuhi.

Untuk pengembang berikutnya: gunakan DESIGN.md/komponen bersama; jangan
menghidupkan kembali Elvis pada hasil launcher, melewati token inspeksi,
menyimpan respons galat sebagai cache positif, atau memberi kode 429 sintetis.
Perubahan tampilan berikutnya perlu retest dialog pendek dan font besar.
